Description

Pour-over is the simplest way to taste the difference between coffees, and this dripper is the simplest way to start. The thick ceramic walls hold heat, so the water temperature stays steady while you pour, and the spiral ribs let air escape for an even extraction.

Set it on any mug or carafe, drop in a #2 cone filter and pour. Pair it with the Ethiopia Guji to see what all the fuss is about.

Details

  • Material: glazed ceramic
  • Fits: standard #2 cone filters
  • Makes: 1 to 3 cups
  • Dishwasher safe

Roaster’s note: “We use this exact dripper for every tasting at the roastery. It’s heavy, it holds heat well, and it’s very hard to break. Ask me how I know.” (Owen, head roaster)
